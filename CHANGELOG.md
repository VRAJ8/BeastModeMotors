# Changelog

## v1.0.0 — 2026-10

Rebuilt from scratch on Laravel 12, combining the earlier Laravel skeleton and the React/Supabase prototype
(`beast-mode-wheels-verse`) into a single Laravel-only platform.

- Public showroom: Livewire inventory with URL-synced filters, vehicle pages, compare, brands, sell/trade-in, contact.
- Test-drive booking with live availability, offers, finance calculator.
- Customer "My Garage" with saved cars, price-drop alerts, bookings and enquiries.
- Filament back-office: vehicles, brands, test drives, leads pipeline, testimonials, customers, dashboard analytics.
- Pest test suite, GitHub Actions CI, Docker image and Render blueprint.
